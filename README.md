# ClimaSaúde: Alertas Preventivos

## Sobre o projeto

O ClimaSaúde: Alertas Preventivos é uma aplicação desenvolvida em Python com o objetivo de consultar condições climáticas e apresentar alertas e orientações preventivas relacionadas à saúde.

O projeto foi desenvolvido como parte de uma atividade extensionista do curso de Análise e Desenvolvimento de Sistemas.

## Objetivos

- Consultar as condições climáticas atuais.
- Informar a temperatura e a umidade do ar.
- Apresentar a sensação térmica e a velocidade do vento.
- Identificar condições climáticas que podem representar riscos à saúde.
- Apresentar alertas preventivos.
- Fornecer recomendações de cuidados relacionados às condições climáticas.
- Utilizar a tecnologia como ferramenta de prevenção e conscientização.

## Tecnologias utilizadas

- Python
- Tkinter
- Requests
- Open-Meteo API

## Funcionalidades

- Consulta de temperatura atual.
- Consulta da umidade relativa do ar.
- Consulta da sensação térmica.
- Consulta da velocidade do vento.
- Identificação de temperaturas elevadas.
- Identificação de temperaturas baixas.
- Identificação de baixa umidade do ar.
- Identificação de ventos fortes.
- Geração de alertas preventivos.
- Apresentação de recomendações relacionadas à saúde.
- Atualização dos dados climáticos por meio da internet.

## Local de aplicação

O projeto foi aplicado na empresa Mili, localizada no bairro Tatuquara, no município de Curitiba, estado do Paraná.
